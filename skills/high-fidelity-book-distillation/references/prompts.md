# Prompt Templates for Users

When useful, offer the user reusable prompts.

## High-Fidelity Single-Book Guide

```text
Turn the following book into a high-fidelity learning guide. Do not reproduce the book. Reconstruct the author's argument in your own words. Include the book's central thesis, problem, argument map, core concepts, major claims, evidence, practical principles, limitations, knowledge-system placement, reading route, and self-test questions. Separate facts, author opinions, anecdotes, and actionable rules. Add original reading pointers by chapter, section, or topic anchor.
```

## Absorption-Oriented Guide

```text
Turn this book into an absorption-oriented guide. Focus on what changes for the reader after reading it. Include reading motivation, the misconception the book corrects, core concepts, argument map, insight moments, before/after shift, practical actions, knowledge-system placement, reading route, review prompts, and output prompts. Do not reproduce long passages.
```

## Comprehensive Guide With Optional Learning Dialogue

```text
Turn this book into a comprehensive high-fidelity guide. Include the author's central argument, problem, argument map, core concepts, evidence, caveats, application ideas, reading route, retention prompts, and what still requires reading the original. After the guide, ask whether I want to continue with a Socratic learning dialogue. If so, ask one question at a time to deepen my understanding of the book's argument, concepts, evidence, limits, applications, and misuse risks.
```

## Socratic Learning Dialogue

```text
Guide me through this book with a Socratic learning dialogue. First give me a minimal book model: the problem the book addresses, the author's central claim, the key concept or distinction I must understand, the main limitation or misuse risk, and one original reading pointer if available. Then ask me one question at a time. Use my answers to identify what is right, incomplete, confused, or worth extending before asking the next question.
```

## Chapter-by-Chapter Study Guide

```text
Create a chapter-by-chapter study guide. For each chapter, extract the core question, main claim, reasoning, evidence, examples, concepts, practical takeaway, caveat, link to the whole-book argument, and original reading pointer. Then synthesize the whole book into one integrated framework.
```

## Fast Reading Plan

```text
Based on this table of contents, create a fast reading plan. Identify which chapters to read deeply, skim, or skip. Explain why. Then give me a 30-minute route, a 2-hour route, and a full study route.
```

## Multi-Book Comparison

```text
Compare these books as a knowledge system. Identify each book's thesis, assumptions, evidence quality, strongest ideas, weak points, overlaps, conflicts, and best use case. Then integrate the strongest ideas into a practical framework. Include original reading pointers for the most important sections.
```

## Practical Action Manual

```text
Convert this book into an action manual. Extract decision rules, checklists, workflows, warning signs, review questions, first-use actions, and a 30-day application plan. Include limits, misuse cases, and source pointers to the original sections behind each major rule.
```

## Critical Evaluation

```text
Evaluate this book critically. What does it get right? What does it overstate? Which claims are empirical, anecdotal, motivational, speculative, context-bound, or outdated? What should a reader apply, and what should a reader treat cautiously? Add source pointers for the claims being evaluated.
```

## Knowledge-System Note

```text
Place this book inside a broader knowledge system. Identify the big question it helps answer, the knowledge node it strengthens, upstream ideas, downstream uses, adjacent readings, gaps, and how it should change my reading plan.
```
