Invite the reader to continue with one-at-a-time learning questions. State the first question you would ask. The question should test understanding of the book's central argument, concepts, evidence, limits, application, or misuse risks. Do not ask the reader to choose another output format.

## Absorption-Oriented Book Guide

Use this structure when the user wants the book to affect thinking or behavior:

```markdown
# Absorption-Oriented Guide to [Book Title]

## Reading Motivation

Explain why a reader might read this book now and what problem it can help with.

## One-Sentence Thesis

State the book's central claim.

## The Misconception the Book Corrects

Explain what the reader may have misunderstood before reading.

## Core Argument Map

Show how the author moves from problem to method, evidence, and application.

## Core Concepts

Define the essential concepts.

## Memorable Cases and Examples

Summarize the examples that carry the argument. Do not reproduce long passages.

## Insight Moments

List the ideas most likely to change the reader's view.

## Emotional Triggers

Include only when relevant. Explain what parts may create resonance, discomfort, relief, grief, courage, or reflection.

## Before / After Shift

- Before:
- Intervention:
- After:

## What to Do With This Book

Give concrete actions, experiments, questions, or writing tasks.

## Knowledge-System Placement

Explain what larger learning theme this book belongs to.

## Reading Route

Tell the reader what to read deeply, skim, skip, and return to.

## Review and Output Prompts

Give prompts for memory, writing, teaching, discussion, or application.
```

## Optional Learning Dialogue Follow-Up

Use this after an ordinary comprehensive guide when the user may want deeper understanding:

```markdown
如果你想继续，我可以进入苏格拉底式深入学习：我会一次只问一个问题，根据你的回答继续追问，帮助你检查是否真正理解了这本书的中心论点、关键概念、证据强弱、应用边界和误用风险。

如果继续，我会先问这个问题：

[Book-specific Socratic question]
```
